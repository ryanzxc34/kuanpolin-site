# kuanpolin.com

Static source for kuanpolin.com, deployed manually to Cloudflare.

## Routes

- `/` — personal site (`index.html`)
- `/services/landing-page/` — Traditional Chinese test offer for a one-page small-business site at NT$1,500. The page does not collect payment.
- `/demo/plant-shop/` — fictional plant-shop demo. Not a client case. Products, prices, and hours are example data.

These paths are files in this repository. They are not on the live site until a reviewed change is deployed.
